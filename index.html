Harmonize Hub

Harmonize Hub is a harm reduction nonprofit operations platform I built — one home for the whole back office, instead of scattered spreadsheets, inboxes, and sticky notes.

Independent project · Nonprofit operations

One connected system for the work behind the work.

Harmonize Hub is an operations platform I designed and built to bring the moving pieces of a harm-reduction program into one place. The goal: fewer disconnected tools, less duplicated work, and a clearer picture of what's happening across the program.

The problem

Requests arrive through different channels. Supply counts, shipping, client records, grant obligations, and reporting can live in separate spreadsheets or in people's heads. That makes routine work harder to track, hand off, and keep consistent.

The system

Twelve connected modules cover the program's operational flow, from request intake and mail orders to inventory, alerts, administration, and reporting. The intent is to make information useful across the workflow instead of re-entering it in each step.

My contribution

I designed the workflow, shaped the modules, and built the application. It began in Base44 and has since transitioned into an Electron desktop app on my PC. This is an ongoing build, not a static mockup.

Harm reduction is home turf

My program experience is in harm reduction, and it shapes how I think about tech. Small harm reduction nonprofits run on small staffs and smaller budgets. There's no IT department. When the website breaks or the tech acts up, the same people packing supply orders end up trying to fix it — if anyone does.

Straight up: I've never run a bad-batch alert system. But alert systems and mail-order supply programs are the kind of work I'm built for. I coordinated a mail-order syringe service program — requests in, supplies packed and shipped, records kept straight — and I designed a Community Alerts module inside Harmonize Hub for getting time-sensitive warnings out to the people who need them. I know this work because I've done it, and I can look after the website and systems behind it.
